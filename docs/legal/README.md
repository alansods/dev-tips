# Páginas legais

Fonte da política de privacidade e dos termos de uso do app. São publicadas no GitHub Pages (branch `gh-pages`) nos endereços configurados em `app.json` → `extra.legal`:

- `https://alansods.github.io/dev-tips/privacidade`
- `https://alansods.github.io/dev-tips/termos`

Antes de publicar, trocar `[DATA DE PUBLICAÇÃO]` pela data do dia. Ao mudar o que o app coleta ou com quem compartilha (por exemplo, login com Apple ou um recurso de IA), atualizar a política junto com a change.
